# Selected Fantasy Town Kit assets

Creator: Kenney (https://kenney.nl).
Pack: https://kenney.nl/assets/fantasy-town-kit version 2.0.
Download mirror posted by Kenney: https://opengameart.org/content/fantasy-town-kit
License: CC0; original License.txt retained in fantasy-town/.

Only tree-high-round (stored as tree.glb), rock-small, rock-large, lantern and
banner-red GLB files are included.
The shared Textures/colormap.png palette is retained at the relative GLB path.
These are scenery assets, not recovered Georama parts. Houses retain separate
shells, doors, roofs and furnishings to preserve assembly and walkable interiors.
