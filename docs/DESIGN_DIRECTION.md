# Game direction

- **Dark Cloud:** core dungeon/weapon/restoration loop, multipart Georama, physical
  exploration, restored residents and in-person requests. Touch substitutes for
  controller input. Avoid turning restoration into a mobile city-builder economy.
- **Dungeon Boss:** chunky characters, expressive silhouettes and readable shapes.
- **Hunt Royale:** colorful low-poly environment readability suited to Android.
- **Bastion:** added by the user as another inspiration. Draw on rich color,
  handcrafted-looking spaces, atmosphere and environmental storytelling. This
  reference does not by itself authorize narration, a fixed isometric camera or
  replacing the approved Dark Cloud loop with another combat/progression system.

Use original identities and properly licensed assets. Create mockups before visual
changes, then compare actual gameplay captures against the target. Improve art
through coherent geometry, materials, lighting and composition; do not substitute
an aspirational image for implemented visual quality.

Approved environment variant (October 29, 2026): subtle steampunk dungeon accents
(sparse copper pipes, brass fittings, gauges and restrained vent steam), and a
papercraft town with matte fibers, visible cardstock edges and thick cutout trees.
Keep the town fully 3D, with free camera orbit, actual doors and walkable interiors.
See images/environment-steampunk-papercraft-concept.png for the target; the alpha
implementation uses much simpler geometry. No new economy or gameplay mechanic
is implied by this visual direction.
